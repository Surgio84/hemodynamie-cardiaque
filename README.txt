HÉMODYNAMIE CARDIAQUE — LABORATOIRE VISUEL INTERACTIF

Contenu du dossier
- index.html : le simulateur complet
- .nojekyll : indique à GitHub Pages de publier le site comme site statique simple

Publication rapide avec GitHub Pages
1. Créez un nouveau dépôt GitHub, par exemple : hemodynamie-cardiaque
2. Téléversez index.html et .nojekyll à la racine du dépôt
3. Ouvrez Settings > Pages
4. Sous Build and deployment, choisissez Deploy from a branch
5. Sélectionnez la branche main et le dossier /(root)
6. Enregistrez
7. Utilisez l'adresse affichée par GitHub Pages comme lien public dans Ardoise

Mise à jour
Pour conserver la même adresse Web, remplacez simplement index.html par une nouvelle version
du simulateur dans le même dépôt.
